# Auto Annotation User Guide

Learn how to configure, execute, and reuse annotation templates across projects with Auto Annotation.

<img src="{{ '/assets/images/logos/AutoAnnotationLight.png' | relative_url }}" alt="Auto Annotation Logo" width="128" style="display:block;margin:0 auto;">

{: .fs-6 .fw-300 }

## Overview

Auto Annotation creates multiple annotation label types by combining annotation settings with scope-based object filtering. You can define where labels are created, standardize templates, and re-execute them across files and projects.

**Key Features:**

- **Multi-annotation setup** - Configure one or more annotation rows and run selected rows together.
- **Annotation settings control** - Define feature, label type, style, and case-specific inputs.
- **Scope and filtering** - Use file scope and OneFilter-style object rules to control label locations.
- **Template/profile workflow** - Save and reuse standardized configurations across projects.
- **Re-execution support** - Recreate labels after updates while preserving relocated label positions.

## Getting Started

### Basic Workflow

1. **Open Auto Annotation** - Launch the tool from the DiRoots tab.
2. **Add Annotation Rows** - Create one or more rows in the main table.
3. **Configure Annotation Settings** - Define feature, label type, and styles per row.
4. **Configure Scope** - Choose where to apply and define object filters.
5. **Check Rows to Execute** - Select only the rows to create annotations.
6. **Apply** - Run Auto Annotation on checked rows.
