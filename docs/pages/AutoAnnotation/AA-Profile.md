# Profile

Auto Annotation includes a profile system to store and reuse complete annotation template configurations across projects.

## Overview

The profile system allows you to:

- Save and reuse standardized Auto Annotation setups.
- Switch quickly between different profile templates.
- Share profile templates across teams and projects.
- Keep annotation logic consistent between project files.

## What's Saved In The Profile

Each profile stores:

- The full set of Auto Annotation rows.
- Per-row **Annotation Settings** (feature, label type, styles, and additional inputs).
- Per-row **Scope** setup (apply-on file scope and object filter definitions).
- Object filter rule logic and target object location definitions.

This structure allows complete annotation templates to be recreated reliably in other projects.
